English

Spanish localization of the D&D5e 2024 Wizard Schools compendium using Babele. Translates the four Wizard subclass folders and the visible text in all 24 documents, preserving their stable IDs and game mechanics.

What's translated?

  • Four Wizard subclasses: Conjurer, Enchanter, Necromancer, and Transmuter.
  • Twenty-four compendium documents: subclass descriptions and features, including visible activity, effect, and advancement text.
  • Native integration: keeps the original compendium and document IDs. No duplicate compendium or mechanical changes.

Requirements

Foundry VTT 14.367+ (verified 14.370), system dnd5e 6.0.3+ (verified 6.0.6), the D&D5e 2024 Wizard Schools base module 2.14.0+, the official Player's Handbook 2024 module and Babele 2.9.1+. These are separate installations.

Installation and activation

  1. Install and activate the base Wizard Schools module, the official PHB 2024 module, and Babele in your dnd5e world.
  2. Install this translation with the Manifest URL and enable it in the world.
  3. Select Español in Foundry's language settings and reload the world.
  4. Open the base module's Wizard Schools compendium to view the translated content.

Limitations

The translation changes visible text only: it does not add subclasses by itself or replace the base compendium. Actor documents previously imported from a compendium are not automatically synchronized after updates. Update the base module before the translation.

Español

Traducción al español mediante Babele de los compendios de D&D5e 2024 — Escuelas de Mago. Traduce las cuatro carpetas de subclases y los textos visibles de sus 24 documentos, conservando los identificadores originales y el funcionamiento de las reglas.

¿Qué contenido traduce?

  • Cuatro subclases de Mago: Conjurador, Encantador, Nigromante y Transmutador.
  • Veinticuatro documentos de compendio: descripciones de subclases y rasgos, incluidos textos visibles de actividades, efectos y avances.
  • Integración nativa: conserva el compendio y los ID originales. No duplica documentos ni altera sus mecánicas.

Requisitos

Foundry VTT 14.367+ (verificado 14.370), sistema dnd5e 6.0.3+ (verificado 6.0.6), D&D5e 2024 Wizard Schools 2.14.0+, el módulo oficial Manual del Jugador 2024 y Babele 2.9.1+. Son instalaciones independientes.

Instalación y activación

  1. Instala y activa el módulo base Wizard Schools, el PHB 2024 oficial y Babele en tu mundo dnd5e.
  2. Instala esta traducción mediante la URL del manifiesto y actívala.
  3. Selecciona Español como idioma de Foundry y recarga el mundo.
  4. Abre el compendio de escuelas de mago del módulo base y comprueba los textos traducidos.

Limitaciones

Solo traduce el texto visible: no añade subclases por sí mismo ni sustituye el compendio base. Las copias previamente importadas a Actores no se sincronizan automáticamente tras las actualizaciones. Actualiza primero el módulo base y después la traducción.
